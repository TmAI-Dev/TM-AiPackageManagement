# Bicep skill

Use this skill for Azure infrastructure and deployment work.

## Standards

- Prefer reusable modules and explicit parameters
- Keep resource naming predictable and environment-aware
- Minimize secret handling in templates
- Use secure defaults and least-privilege access patterns
- Keep deployments readable and maintainable

## Common expectations

- parameterized environment setup
- clear outputs for downstream tooling
- resource tagging and ownership conventions
- deployment safety and idempotency
