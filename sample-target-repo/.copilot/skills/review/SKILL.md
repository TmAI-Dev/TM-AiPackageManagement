# Review skill

Use this skill when reviewing code or design decisions.

## Standards

- Focus on correctness and maintainability first
- Separate blockers from suggestions
- Be specific and evidence-based
- Explain the impact of issues in practical terms
- Prefer clarity and smaller scope over cleverness

## Common expectations

- actionable feedback
- review comments grounded in code evidence
- recognition of trade-offs and constraints
- recommendations that improve confidence and quality
