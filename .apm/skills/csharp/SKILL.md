# C# skill

Use this skill for .NET, C#, ASP.NET Core, libraries, and related backend work.

## Standards

- Prefer immutable data and clear object boundaries
- Use async/await correctly and avoid blocking calls
- Keep interfaces and classes focused and coherent
- Favor typed, explicit models over implicit magic
- Validate edge cases and failure paths

## Common expectations

- production-safe error handling
- clear dependency boundaries
- good naming and method responsibilities
- relevant tests for changed behavior
