# Razor Pages skill

Use this skill for ASP.NET Core Razor Pages work.

## Standards

- Keep PageModels thin; put logic in injected services
- Use async handlers and Post-Redirect-Get for forms
- Validate with data annotations and protect against over-posting
- Keep antiforgery enabled and rely on default output encoding

## Common expectations

- partials, view components, and tag helpers for reuse
- authorization policies on pages and handlers
- accessible, semantic markup
