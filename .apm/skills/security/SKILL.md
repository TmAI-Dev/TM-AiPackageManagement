# Security skill

Use this skill for security reviews, secure coding guidance, and risk analysis.

## Standards

- Prefer least privilege and secure defaults
- Never hard-code credentials or tokens
- Validate assumptions about data exposure and trust boundaries
- Treat input validation as a first-class concern
- Prefer mitigations that are practical and verifiable

## Common expectations

- clear risk identification
- actionable mitigation recommendations
- awareness of OAuth, secret storage, APIs, and infrastructure exposure
- emphasis on real-world security trade-offs
