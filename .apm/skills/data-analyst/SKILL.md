# Data analyst skill

Use this skill for data science and data analysis work.

## Standards

- Check data quality before analysis
- Start with simple, interpretable methods and baselines
- Use vectorized operations; set random seeds for reproducibility
- Keep secrets and personal data out of notebooks and outputs

## Common expectations

- state assumptions and limitations alongside findings
- avoid leakage, misleading charts, and over-claiming from small samples
- document data sources, versions, and dependencies
