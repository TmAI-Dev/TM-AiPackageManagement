# AI evaluation skill

Use this skill for evaluating models, prompts, retrieval, and agents.

## Standards

- Define success criteria and compare changes against a baseline
- Include representative normal, edge, failure, and adversarial cases
- Record model versions, configurations, datasets, and run conditions
- Protect sensitive data and distinguish measured results from estimates

## Common expectations

- quality, safety, latency, and cost metrics appropriate to the task
- human review of automated graders and documented evaluation limitations
