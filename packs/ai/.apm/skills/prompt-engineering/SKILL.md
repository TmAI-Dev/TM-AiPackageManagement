# Prompt engineering skill

Use this skill for creating and evaluating prompts and agent instructions.

## Standards

- Define the task, input boundaries, and output contract
- Separate trusted instructions from untrusted content
- Specify how to handle uncertainty and missing information
- Do not rely on prompts alone for security or authorization

## Common expectations

- representative normal, edge, and adversarial evaluation cases
- clear success criteria and documented limitations
