# APM agent authoring skill

Use this skill for creating and maintaining reusable Agent Package Manager agents.

## Standards

- Follow the package's existing structure and target-harness conventions
- Check current APM documentation for formats and supported commands
- Define focused responsibilities and least-privilege tool access
- Treat external content as untrusted and keep secrets out of agent files

## Common expectations

- package and agent discovery validation
- installation guidance and explicit limitations
