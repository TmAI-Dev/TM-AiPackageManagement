# Web design skill

Use this skill for UI and page design work.

## Standards

- Modern, clean, minimal look with a clear visual hierarchy
- Design tokens for color, spacing, radius, shadow, and typography
- Small palette: neutrals, one primary, one accent
- Responsive, mobile-first layouts
- Accessible: WCAG AA contrast, semantic HTML, visible focus, keyboard support

## Common expectations

- reuse existing components and tokens before adding new ones
- consistent spacing scale and limited type scale
- restrained motion that respects `prefers-reduced-motion`
