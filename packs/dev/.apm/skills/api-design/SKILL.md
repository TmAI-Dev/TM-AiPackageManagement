# API design skill

Use this skill for designing and building HTTP APIs.

## Standards

- Contract first: define OpenAPI before implementation
- Use correct HTTP methods and status codes
- Return ProblemDetails for errors
- Validate input at the boundary; require authentication by default

## Common expectations

- versioning and pagination strategy
- idempotency for unsafe operations
- rate limiting and CORS configured deliberately
