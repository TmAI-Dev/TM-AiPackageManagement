# Theme consistency skill

Use this skill whenever a color template or styling is added or changed on a page.

## Standards

- Define the theme once (CSS variables, theme resources, or framework equivalent)
- Apply the same theme to every page, layout, and component in the solution
- Replace hard-coded colors and inline styles with theme tokens
- Never add colors outside the theme

## Checklist

- search all pages, layouts, partials, and components
- check header, footer, navigation, buttons, forms, tables, cards, and links
- check hover, focus, disabled, and error states
- check contrast in each theme variant
- report pages updated and any remaining inconsistencies
