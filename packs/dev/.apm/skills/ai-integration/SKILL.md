# AI integration skill

Use this skill for building features on LLMs and Azure AI services.

## Standards

- Use managed identity, not API keys
- Treat user and retrieved content as untrusted input
- Validate and constrain model output
- Set token limits, timeouts, and retry handling

## Common expectations

- RAG with Azure AI Search for grounded answers
- evaluation of quality and safety before release
- cost and latency estimates
