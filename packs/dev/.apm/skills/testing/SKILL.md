# Testing skill

Use this skill for writing and improving automated tests.

## Standards

- Follow the repo's existing test framework and layout
- Use arrange-act-assert with descriptive test names
- Keep tests isolated, deterministic, and fast
- Mock external services; no real Azure calls in unit tests

## Common expectations

- xUnit for C#, Pester v5 for PowerShell, pytest for Python
- edge cases and failure paths covered
- CI-friendly execution
