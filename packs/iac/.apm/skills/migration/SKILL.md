# Migration skill

Use this skill for moving and modernizing workloads.

## Standards

- Assess dependencies and compatibility before choosing a strategy
- Prefer incremental migration with a tested rollback plan
- Define success criteria and validation steps
- Estimate downtime, cost, and risk per option

## Common expectations

- phased plan with cutover steps
- identity and networking addressed early
- open questions and assumptions listed
