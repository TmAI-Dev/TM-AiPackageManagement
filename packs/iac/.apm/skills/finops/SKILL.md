# FinOps skill

Use this skill for Azure cost management and optimization.

## Standards

- Rank savings by impact and effort
- Check performance and reliability impact before downsizing
- Enforce tagging for cost allocation
- Prefer reservations or savings plans for steady workloads

## Common expectations

- orphaned and idle resource detection
- budgets and alerts
- quantified estimates with stated assumptions
