# Azure architect skill

Use this skill for Azure architecture and design decisions.

## Standards

- Evaluate designs against the Well-Architected Framework pillars
- Clarify requirements, SLAs, and constraints first
- Present options with trade-offs and a recommendation
- Prefer managed services and private networking by default

## Common expectations

- diagrams for topology and data flow
- stated RTO/RPO and cost implications
- assumptions and open questions listed
