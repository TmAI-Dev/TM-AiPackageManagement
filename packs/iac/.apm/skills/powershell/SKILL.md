# PowerShell skill

Use this skill for automation, Windows scripting, and operational tooling.

## Standards

- Validate inputs with clear parameters
- Avoid silent failures
- Use structured logging where helpful
- Keep script behavior predictable and idempotent
- Prefer explicit output and clear exit codes

## Common expectations

- environment-safe assumptions
- simple but robust parameter handling
- proper trap/error handling
- secure management of credentials and paths
