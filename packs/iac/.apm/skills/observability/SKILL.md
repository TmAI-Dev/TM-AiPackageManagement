# Observability skill

Use this skill for monitoring, telemetry, and alerting.

## Standards

- Instrument with OpenTelemetry and Application Insights
- Alert on user-impacting symptoms with a clear owner
- Never log secrets or personal data
- Define monitoring as code

## Common expectations

- diagnostic settings enabled on key resources
- sampling and retention set with cost in mind
- SLOs defined for critical services
