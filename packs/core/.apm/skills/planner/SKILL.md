# Planning skill

Use this skill for producing actionable implementation plans.

## Standards

- Inspect the relevant code and conventions before planning
- Separate observed facts from assumptions and open decisions
- Break work into steps with explicit dependencies and acceptance criteria
- Do not change code or infrastructure unless explicitly asked

## Common expectations

- proportionate validation and rollout considerations
- risks, trade-offs, and unresolved questions
