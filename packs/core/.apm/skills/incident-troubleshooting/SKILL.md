# Incident troubleshooting skill

Use this skill for diagnosing failures and outages.

## Standards

- Establish impact, scope, and recent changes first
- Use read-only diagnostics before making changes
- Work hypothesis by hypothesis, with evidence
- Separate mitigation from root-cause fix

## Common expectations

- timeline of events
- logs and metrics from Azure Monitor and Log Analytics
- follow-up actions to prevent recurrence
