# Docs skill

Use this skill for technical documentation.

## Standards

- Structure: purpose, prerequisites, steps, verification, troubleshooting
- Ground content in the actual repo; verify paths and commands
- Update existing docs rather than duplicating
- Use ADRs for significant decisions and Mermaid for diagrams

## Common expectations

- copy-pasteable commands with the target shell noted
- consistent terminology and headings
- no secrets or internal-only identifiers
