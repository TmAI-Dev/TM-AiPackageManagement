# Brainstorm skill

Use this skill when exploring ideas, features, or direction for an application.

## Standards

- Frame the problem and users first
- Offer several distinct options, not a single answer
- Include at least one unconventional idea
- Compare options by value, effort, and risk
- Fit suggestions to the existing architecture and conventions
- End with a recommendation and concrete next steps

## Techniques

- "What if" and constraint flipping
- user journey and pain-point review
- quick wins versus long-term bets
- reuse of existing components before new builds
