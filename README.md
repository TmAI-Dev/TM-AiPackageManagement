# Agent Package Management

This repo is a central catalog of reusable Copilot agents and skills that can be synced into any repository you want to work in.

## Goals

- Keep one authoritatively maintained set of agents and skills
- Avoid duplicating agent definitions across repositories
- Make it easy to copy the same setup to multiple repos
- Allow repo-specific overrides without rewriting the shared pack

## Recommended model

Use this central repo as the source of truth. Then use the bootstrap script to copy the pack into repo(s) that need it.

### Shared pack

The shared pack should always hold the common defaults:

- C# agent
- PowerShell agent
- Bicep agent
- Security agent
- Review agent
- Code quality agent

### Repo local additions

Keep repo-specific instructions in the target repo, not in the central pack, when they depend on application-specific rules.

## Bootstrap flow

From the repo root:

```powershell
pwsh ./scripts/bootstrap-agent-pack.ps1 -TargetRepos "C:/path/to/repo-1", "C:/path/to/repo-2"
```

The script will:

- create a `.copilot/agents` folder in each target repo
- create a `.copilot/skills` folder in each target repo
- copy the shared agent and skill definitions into those locations
- create a short manifest so the repo can see what was installed

## Notes

This repository is intentionally not tied to one application. It acts as the shared package source for all your repositories.

If you later want stricter repo-level integration with VS Code Copilot files or custom instruction discovery, the pack can be extended without changing the central design.
