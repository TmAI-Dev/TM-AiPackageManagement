# Code quality skill

Use this skill for maintainability, readability, and engineering hygiene.

## Standards

- Prefer simple, explicit, well-named logic
- Minimize duplication and complexity
- Keep responsibilities narrow and understandable
- Make code easier to test and modify
- Prefer stability over cleverness

## Common expectations

- quality-focused refactoring suggestions
- maintainability review findings
- consistent patterns and cleaner boundaries
- practical adjustments that lower long-term cost
